## 🚀 Featured Projects

The portfolio showcases four key engineering projects, each grounded in real-world use cases, clean architecture, and practical software design:

### 1. [Darna Clean](https://saad-larouchi.vercel.app/projects/darna-clean) — Mobile Booking Application
* **Overview:** A native Android booking application that connects homeowners with vetted cleaning professionals in Morocco, establishing a reliable, structured digital alternative to informal word-of-mouth booking.
* **Key Capabilities:** Service booking and scheduling, modern UI built with Jetpack Compose, real-time Firebase backend synchronization, and live booking status updates.
* **Tech Stack:** Kotlin, Jetpack Compose, Firebase, SQLite.
* **Case Study:** [View Darna Clean Case Study](https://saad-larouchi.vercel.app/projects/darna-clean)

### 2. [Allo Brikol](https://saad-larouchi.vercel.app/projects/allo-brikol) — Dual-Platform Home Repair Marketplace
* **Overview:** A dual-platform marketplace connecting customers with local home repair and maintenance providers, providing a seamless mobile interface for clients and a web management dashboard for service professionals.
* **Key Capabilities:** Provider discovery and booking system, transparent ratings and reviews, provider profile management, and real-time authentication.
* **Tech Stack:** Flutter, React, TypeScript, Tailwind CSS, Laravel API.
* **Case Study:** [View Allo Brikol Case Study](https://saad-larouchi.vercel.app/projects/allo-brikol)

### 3. [ServeGX](https://saad-larouchi.vercel.app/projects/servegx) — Mobile Server Telemetry & Monitoring App
* **Overview:** A lightweight Android telemetry and monitoring tool created for system administrators to observe server infrastructure metrics on the go without opening heavyweight desktop interfaces.
* **Key Capabilities:** Live CPU, RAM, disk, and network monitoring; threshold-based notifications and alerts; and historical metrics reporting.
* **Tech Stack:** Kotlin, Java, Android SDK.
* **Case Study:** [View ServeGX Case Study](https://saad-larouchi.vercel.app/projects/servegx)

### 4. [Luxeldo](https://saad-larouchi.vercel.app/projects/luxeldo) — Luxury Timepiece E-Commerce Storefront
* **Overview:** A digital e-commerce storefront for a Moroccan retailer of Swiss-made luxury timepieces, emphasizing visual brand consistency, responsive design, and search visibility.
* **Key Capabilities:** Curated product presentation, high-performance responsive catalog layout, brand identity integration, and structured data optimization.
* **Tech Stack:** HTML5, CSS3, JavaScript, E-commerce Architecture.
* **Case Study:** [View Luxeldo Case Study](https://saad-larouchi.vercel.app/projects/luxeldo)

## 💻 Repository Structure & Local Development

This portfolio repository is built with:
* **Core:** React 19, TypeScript, Vite
* **Styling & Motion:** Tailwind CSS v4, Framer Motion, Lucide React
* **Localization:** i18next (English, French, Arabic with RTL direction handling)
* **Pre-rendering:** Custom Node.js static generation script (`scripts/prerender.cjs`) producing dedicated HTML snapshots and unified JSON-LD metadata for all project routes.

### Getting Started

```bash
# Clone the repository
git clone https://github.com/saadlarouchi/saad-larouchi-portfolio.git

# Navigate into the project directory
cd saad-larouchi-portfolio

# Install project dependencies
npm install

# Run local development server
npm run dev

# Build for production and generate pre-rendered static routes
npm run build

# Run code linter
npm run lint
```
